# NexTep - Karate DX Platform 🥋

空手競技におけるデジタル・トランスフォーメーション (DX) を実現する、次世代型のリアルタイム・ライブスコアリング & 選手分析プラットフォームです。
大会運営スタッフや指導者がリアルタイムに試合の進行管理・採点を行い、自動的に蓄積されたデータから各選手のパフォーマンス分析（アナリティクス）を視覚的に統合します。

---

## 🎨 デザインコンセプト & ビジュアルアイデンティティ

本アプリケーションは、**「Cosmic Slate / Retro Future」** をデザインテーマに採用しています。
*   **洗練されたタイポグラフィ:** タイトルには力強いイタリック調のブラック・サンセリフフォントを採用し、競技の躍動感を演出。デジタルインジケーターには視認性の高い等幅フォント（モノスペース）を組み合わせ、直感的でミスのない操作性を提供します。
*   **計算されたカラーパレット:** 白とディープ・ネイビー（チャコール）をベースとした高コントラストかつ目に優しい配色。競技者側の色（AKA/赤、AO/青）を正確にゾーニングし、視覚的な誘導を行います。
*   **ドットグリッド・パターン:** バックグラウンドに繊細なドットパターン（グリッド放射グラデーション）を敷くことで、クラシックかつ洗練された未来感を表現しています。

## 🚀 主な機能

### 1. セキュアなスタッフ認証（AuthOTP）
*   ワンタイムパスワード（6桁の認証コード）を入力するシームレスなセキュリティ認証画面。
*   ボタンの物理的な押し心地や状態変化を表現するネオブルータリズム調の立体フォーム。

### 2. 選手選択（Athlete Selection）
*   対戦選手（AKA：赤 / AO：青）の直感的な組み合わせインターフェース。
*   各選手の段位、所属団体、過去の大会戦績、直近の勝敗データをその場で簡単に確認・変更可能。

### 3. フロー重視の試合設定（Match Settings）
*   **DURATION (試合時間ダイヤル):** ダイヤルスライダーによる高精度な時間設定（0:00 〜 9:59）。
*   **POINT LIMIT:** 目標とする上限ポイント（1 PT 〜 15 PTS）の直観的なスライダー調整。
*   **SENSHU (先取スイッチ):** 同点時に先取スコア獲得者に優位性を付与するルールのトグルスイッチを、POINT LIMITと同じ同一ブロック内に美しく統合。
*   **勝利条件の即時選択:** 「先き取り（SENSHU最優先）」と「差 (SA - 例: 8点差付きでコールド)」の勝利ルールを2つの大きな物理的ボタンからワンクリックで適用可能。

### 4. 厳格なリアルタイム・ライブスコアリング（Live Scoring）
*   **フロー制御された連続入力システム:** 部位（Jodan / Chudan / None）、技術（Tsuki / Keri / None）、および判定（Yuko / Waza-ari / Ippon / C1 / C2）が論理的に繋がる入力インターフェース。
*   **【重要】タイマー連動型スコアロック機能:**
    *   試合（タイマー）稼働中は画面上部に **「MATCH IN PROGRESS」** の警告アニメーションブレードが表示され、ボタン操作・スコア追加が自動的にロックされます。
    *   これにより、審判員や操作卓のボタン誤フリック・誤判定入力をシステム的に完全にブロックします。
    *   タイマーが一時停止（STOP）した安全な状態でのみ、確実なスコアの追加・編集を行うことができます。
*   **コールド判定・決着自動監視:**
    *   「目標スコア到達」「設定した点差の開き」「タイムアップ」の3つの終了条件をリアルタイムに自動監視。
    *   試合終了（Match Ended）条件を満たした瞬間に自動でタイマーが停止し、結果表示モード（Trophy）へと画面が遷移します。
*   **安心の取り消し・再試行機能:**
    *   万が一の入力ミスの際にも、タイマー停止時に活用できる無制限の **Undo (元に戻す)** / **Redo (やり直す)** を搭載。

### 5. 高度な選手アナリティクス（Athlete Insights）
*   対戦データの追跡とチャート分析の統合。
*   Rechartsを用いたインタラクティブなレーダーチャートによる「攻撃力、守備力、スピード、スタミナ、勝率」の5軸パラメータ可視化。
*   過去の勝敗タイムラインやスコア経過の履歴ログフィード。

## ⚙️ テクノロジースタック

*   **Frontend Framework:** React 19 + TypeScript
*   **Build Utility:** Vite
*   **Styling:** Tailwind CSS (高速で高度に設計されたユーティリティテーマ)
*   **Animations:** Motion (`motion/react` による高級なイージングとインタラクティブ・フィードバック)
*   **Icons:** Lucide React (統一されたミニマルなベクターインジケーター)
*   **Components & Inputs:** `input-otp` によるOTP入力スロット構成

## 🛠️ 開発とビルド方法

### 1. 依存関係のインストール
```bash
npm install
```

### 2. 開発サーバーの立ち上げ
```bash
npm run dev
```
開発サーバーは規定のローカルポート（例: `http://localhost:3000`）で起動します。

### 3. 静的プロダクションビルダー
```bash
npm run build
```
Viteビルドにより、最適化およびチャンク統合されたアセットファイル群が `/dist` 下に生成されます。

### 4. リンター（静的型チェック）の実行
```bash
npm run lint
```
TypeScriptコンパイラ (`tsc --noEmit`) を用いた型安全性の検証が実行されます。
